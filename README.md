# ระบบแจ้งข้อมูลเข้าพักของพนักงาน

Web app แยกจากระบบจัดทำเอกสารเบิกเดิม ใช้สำหรับให้พนักงานส่งข้อมูลการเข้าพัก และให้ Admin ตรวจเอกสาร จัดผู้พักร่วม ใส่ราคา ใบเสร็จ และส่งออกข้อมูลสำหรับทำเบิก

ระบบมีบัญชีแยกสำหรับ Admin และ Staff ตามค่าที่กำหนดไว้ รหัสผ่านถูกเก็บในรูปแบบแฮช ไม่ได้บันทึกเป็นข้อความปกติ

## เปิดใช้งาน

ดับเบิลคลิก `run_app.bat` แอปจะเปิดที่ `http://localhost:8502`

ข้อมูลของแอปนี้เก็บแยกอยู่ในโฟลเดอร์ `data` และไม่ใช้ฐานข้อมูลร่วมกับ `accommodation_claim_app`

## ขั้นตอนทำงาน

1. Admin เพิ่มรายชื่อโรงแรมที่อนุญาตให้พนักงานเลือก
2. พนักงานกรอกเลข SA/BT รหัส ชื่อ สาขา โรงแรม ห้อง และช่วงวันที่
3. ระบบจำชื่อและสาขาที่ประจำจากรหัสพนักงานเพื่อเติมให้อัตโนมัติครั้งถัดไป
4. พนักงานแก้ไขรายการของตนได้ตราบใดที่ Admin ยังไม่ดึงไปทำเบิก
5. Admin ตรวจข้อมูลพนักงานและบันทึกใบเสร็จ
6. Admin เลือกพนักงานไม่เกิน 2 คนต่อห้อง เลือกผู้เบิกหลัก ใส่ราคาต่อคืนและเพดาน BT
7. เมื่อ Admin นำข้อมูลไปสร้างรายการห้อง ระบบจะล็อกข้อมูลพนักงานโดยอัตโนมัติ
8. ระบบตรวจเรท SA 600 บาทรวม VAT ส่วน BT ใช้เพดานที่ Admin ระบุ
9. หากเกินเพดาน ระบบแสดงสถานะรอ Mail อนุมัติ
10. ส่งออก Excel แยก SA/BT หรือทั้งหมด โดยมีชีต `BT_Form_Input` สำหรับคัดลอกเลข BT หนึ่งเลขต่อบรรทัด

## ข้อกำหนดที่ควรตัดสินใจก่อนนำขึ้นใช้งานจริง

- ก่อนเปิดผ่านอินเทอร์เน็ตควรเปลี่ยนรหัสผ่านเริ่มต้น และเก็บค่าแฮชไว้ใน Streamlit Secrets
- ผู้มีสิทธิ์แก้ไข/ยกเลิกรายการหลังพนักงานส่งแล้ว
- รายชื่อตำแหน่งและเพดานเบิก BT เพื่อให้ระบบตรวจอัตโนมัติแทนการกรอกมือ
- รูปแบบเอกสารปลายทาง SA และ BT ที่ต้องสร้างเป็น PDF หรือ Excel
- นโยบายเก็บเอกสารส่วนบุคคล อายุข้อมูล และการสำรองข้อมูล

รายละเอียดการนำขึ้นอินเทอร์เน็ตและโครงสร้างฐานข้อมูลอยู่ใน `DEPLOYMENT.md` และ `supabase_schema.sql`

## โครงสร้างข้อมูล

- `data/database.json` — ข้อมูลหลักของระบบ
- `data/uploads/receipts` — ไฟล์ใบเสร็จ
- `data/uploads/approvals` — Mail อนุมัติกรณีเกินเรท
- `data/outputs` — พื้นที่สำหรับไฟล์ส่งออกในอนาคต
